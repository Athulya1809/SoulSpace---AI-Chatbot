SoulSpace AI Chatbot

Project Overview
SoulSpace is an AI-powered chatbot designed to provide emotional support, friendly conversation, relaxation guidance, and mood tracking. The chatbot interacts 
naturally with users, allowing them to share thoughts, feelings, and daily experiences while receiving positive reinforcement, relaxation suggestions, and 
motivational support. The system also maintains conversation history and mood tracking to enhance personalized interactions over time. It aims to help users 
express their feelings and engage in wellness activities.

Features
* User registration and login
* AI chatbot for emotional support
* Conversation history
* Mood journal and mood tracking
* Breathing exercises
* Guided relaxation
* Wellness activities and games
* User profile management
* Admin dashboard and analytics

Technologies Used
* Frontend: HTML, CSS, JavaScript
* Backend: Python and Flask
* Database: MongoDB
* Tools: GitHub and MongoDB Compass

Project Structure
The project contains frontend pages, backend application files, styling resources, scripts, and supporting modules.

How to Run
1. Download or clone this repository.
2. Install Python and the required dependencies.
3. Configure your MongoDB connection and any required environment variables.
4. Install dependencies using `pip install -r requirements.txt`, if the file is available.
5. Run the application using the appropriate Python entry-point file.
6. Open the local URL displayed by the application in your browser.

Purpose
The purpose of SoulSpace is to provide a supportive digital companion that encourages emotional expression and promotes emotional wellness.
